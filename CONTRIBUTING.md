# Contributing to WayFind

Thanks for your interest in contributing! Contributions, questions, and suggestions are welcome through GitHub Issues and Pull Requests.

## How to contribute

1. Open an issue to discuss a substantial change or report a bug. For small fixes, you may open a pull request directly.
2. Fork the repository and create a focused branch from `main`.
3. Make the smallest change that addresses the issue. Avoid unrelated refactors.
4. Run the relevant tests, linters, and build checks; include the commands and results in your PR.
5. Open a pull request against `main`, explain the motivation and implementation, and link related issues.
6. A project maintainer will review the contribution and decide whether to request changes or merge it. Opening a PR does not guarantee acceptance or grant write access.

## Expectations

- Be respectful, constructive, and follow the Code of Conduct.
- Do not submit secrets, credentials, personal information, or real child/family data, including images, in issues, commits, tests, or pull requests. Use synthetic examples only.
- Do not include unlicensed third-party code or data. Identify third-party dependencies and content you add.
- Keep changes relevant to the repository and update documentation or tests when behavior changes.
- Do not represent an unreviewed change as approved or as a validated child-safety decision.

## Local development

Follow the setup and test instructions in this repository's `README.md`. If a required step is unclear or unavailable, mention that in your PR rather than claiming checks passed.
