# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests. Use GitHub's **Report a vulnerability** option on the repository's Security tab (private vulnerability reporting / security advisories), if available. If that option is unavailable, contact the organization owners privately through GitHub and include only the information needed to understand and reproduce the issue.

Do not include real child, family, reporter, or case information, photos, credentials, or other sensitive personal data in a report. Use synthetic data wherever possible. Do not publicly disclose a vulnerability until the maintainers have had a reasonable opportunity to investigate and coordinate a fix.

## Scope and safety

These repositories are not an emergency reporting or response service. Do not use them to submit active missing-child reports or real case records. If a child is in immediate danger, contact local emergency services or the appropriate child-protection authority.

Security reports are reviewed by maintainers, but no response or remediation timeframe is guaranteed. Please include the affected repository and version/commit, impact, and safe reproduction steps.
